# 💻 CSharp-OOP

A collection of C# practice projects covering **Object-Oriented Programming (OOP)** concepts through simple, practical examples.

## 📂 Projects

### 1. 📘 OOP-Basics

* Classes and Objects
* Methods
* Method Overloading

### 2. 🔢 OOP-Variables

* Instance Variables
* Static Variables
* Constant (`const`) Variables
* Readonly Variables

### 3. 🔧 Params-and-Extension-Methods

* `params` Keyword
* Extension Methods

### 4. 🔄 Ref-and-Out-Keywords

* `ref` Keyword
* `out` Keyword
* Passing Parameters by Reference

### 5. 🧩 Partial-and-Static-Classes

* Partial Classes
* Static Classes

### 6. 👨‍💼 Inheritance

* Base and Derived Classes
* Property Inheritance
* Code Reusability

### 7. 🗂️ Struct-Enum-Nullable

* Structures (`struct`)
* Enumerations (`enum`)
* Nullable Types

### 8. 🏗️ Abstract-Class-and-Interface

* Abstract Classes
* Abstract Methods
* Interfaces
* Method Overriding
* Interface Implementation

## 🛠️ Technologies Used

* C#
* .NET
* WPF (Windows Presentation Foundation)
* XAML

## 🎯 Purpose

The purpose of this repository is to strengthen C# programming skills by practising OOP concepts through hands-on examples. Each folder focuses on specific concepts and demonstrates how they work in C#.

## 📚 Learning Approach

These practice projects help build a strong foundation in classes, objects, methods, variables, inheritance, abstraction, interfaces, and other fundamental C# concepts.
